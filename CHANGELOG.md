# Changelog

All notable changes to the Queens-Thesis project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2021-08-15

### Added
- Initial thesis submission
- Complete Bayesian statistical analysis
- EEG spectral analysis for meditation states
- Comprehensive literature review on memory consolidation
- Three-condition experimental design (meditation, napping, wakefulness)
- Declarative and non-declarative memory tasks
- Sleep stage analysis and SWS effects
- Gender difference analyses
- Complete appendix with consent forms and questionnaires
