# Contributing to Queens-Thesis

Thank you for your interest in contributing to this thesis project! This is a completed academic thesis, but we welcome feedback, suggestions, and improvements.

## How to Contribute

### Reporting Issues

If you find any issues with the code, documentation, or have suggestions for improvements:

1. Check if the issue already exists in the [Issues](https://github.com/mohdasti/Queens-Thesis/issues) section
2. If not, create a new issue with:
   - A clear, descriptive title
   - Detailed description of the issue or suggestion
   - Steps to reproduce (if applicable)
   - Expected vs. actual behavior

### Suggesting Enhancements

We welcome suggestions for:
- Code improvements and optimizations
- Documentation enhancements
- Additional analyses or visualizations
- Reproducibility improvements

### Code Contributions

While this is a completed thesis, we may accept contributions for:
- Bug fixes
- Documentation improvements
- Code refactoring for better readability
- Additional analysis scripts

## Development Guidelines

### Code Style

- Follow R style guidelines (use `styler` package)
- Use meaningful variable and function names
- Add comments for complex analyses
- Follow the existing code structure

### Documentation

- Update README.md if adding new features
- Document any new functions or analyses
- Maintain the existing documentation structure

### Testing

- Test any changes with the existing data
- Ensure reproducibility of results
- Verify that existing analyses still work

## Academic Integrity

Please note that this is an academic thesis. Any contributions should:
- Maintain the integrity of the original research
- Not alter the core findings or conclusions
- Be clearly documented as additions or improvements
- Respect the original author's work

## Getting Help

If you have questions about contributing:
- Open an issue with the "question" label
- Check existing issues and discussions
- Review the thesis documentation
